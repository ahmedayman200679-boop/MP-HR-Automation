How it works

Every submission and question executes through production n8n workflows across 5 coordinated stages:

1
Candidate Application Intake & Deduplication

The candidate completes a custom form. The workflow checks for prior submissions in Google Sheets within 90 days, stores the CV in Google Drive, and notifies hiring managers.

⚡ On form submission → Validate Submission → Check Duplicate → ☁️ Upload file (Drive) → 📊 Append row in sheet
2
Autonomous AI Resume Scanner & Evaluator (AI Scan)

Runs hourly to pull pending candidates from Google Sheets, performs multimodal OCR with Google Gemini on complex PDFs, scores competencies with Groq (120B), and automates email decisions.

⏰ Every Hour → 📊 Get row(s) in sheet → 👁️ OCR Scanner Gemini → ⚡ Groq 120B Scoring → Switch Decision → ✉️ Gmail Update
3
Multi-Agent Career Advisory & Interview Coach

A Senior Career Coach agent coordinates 3 tool sub-agents: CV Matcher evaluates fit, Cover Letter Writer crafts tailored letters, and Interview Coach generates mock questions.

⚡ Form Submission → 🤖 Lead AI Coach → 🛠️ CV Matcher + 🛠️ Cover Letter Writer + 🛠️ Interview Coach → ✉️ Email Report
4
Autonomous HR Policy RAG Assistant

Syncs the Employee Handbook from Google Drive, creates vector embeddings via Google Gemini, and uses conversational window memory to answer employee questions with verified citations.

💬 Chat Trigger → 🧠 Simple Memory → 📚 Simple Vector Store → 🤖 HR Agent (Groq/Gemini) → Verified Output
5
Ops Sentinel & Health Watchdog

Traps unexpected workflow errors in real time, applies a 15-minute alert throttle to prevent notification storms, delivers daily 8:00 AM health recaps, and unblocks stuck candidate jobs.

⚠️ Error Trigger → Check Throttle → 📊 Log Error (Sheets) → ✉️ Alert Admin
